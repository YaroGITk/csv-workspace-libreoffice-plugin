# CSV Workspace

**CSV Workspace** — расширение для LibreOffice Calc, которое позволяет работать с несколькими CSV-файлами как с одним рабочим набором.

Каждый CSV-файл открывается в отдельном листе Calc. Набор хранит связь между листами и исходными CSV, поэтому можно:

- открыть сразу весь набор;
- добавить несколько CSV в один документ;
- обновить один лист из исходного CSV;
- обновить все листы;
- изменить данные в Calc и записать их обратно в CSV;
- настроить кодировку, разделитель, кавычки, окончания строк и резервные копии отдельно для набора и отдельных файлов.

Расширение предназначено для **Windows, macOS и Linux**.

## Как устроен CSV Workspace

Рабочий набор состоит минимум из двух частей:

1. **manifest-файл** с расширением `.csvset.json`;
2. **ODS-документ** LibreOffice Calc с листами набора.

Исходные CSV-файлы остаются обычными файлами на диске.

Пример:

```text
analysis/
├── analysis.csvset.json
├── analysis.csvset.ods
└── csv/
    ├── students.csv
    ├── attendance.csv
    └── results.csv
```

`analysis.csvset.json` хранит настройки и связи:

```text
лист Calc ↔ CSV-файл
```

Например:

```text
students   ↔ csv/students.csv
attendance ↔ csv/attendance.csv
results    ↔ csv/results.csv
```

Сам `.ods` нужен как рабочий документ Calc. Источником CSV-данных при обновлении остаются CSV-файлы.

## Установка

### Через LibreOffice

1. Откройте LibreOffice.
2. Откройте менеджер расширений:
   **Сервис → Расширения** / **Tools → Extensions**.
3. Нажмите **Добавить**.
4. Выберите файл:

```text
csvworkspace.oxt
```

5. Подтвердите установку.
6. Полностью закройте LibreOffice.
7. Запустите LibreOffice снова.

После установки появится меню:

```text
CSV Workspace
```

Меню доступно в Calc. Если установлена версия конфигурации со `StartModule`, пункты создания и открытия набора также доступны из стартового окна LibreOffice.

### Если меню не появилось

Полностью завершите LibreOffice, включая фоновые процессы, и запустите снова.

Если это не помогло, удалите старую версию расширения через менеджер расширений, перезапустите LibreOffice и установите `.oxt` заново.

## Быстрый старт

Типичный сценарий:

1. Выберите **CSV Workspace → Создать набор...**
2. Выберите один или несколько CSV.
3. Сохраните manifest, например:

```text
analysis.csvset.json
```

4. LibreOffice создаст рабочий документ:

```text
analysis.csvset.ods
```

5. Каждый CSV появится в отдельном листе.
6. Работайте с данными в Calc.
7. Чтобы записать изменения обратно в CSV, используйте:

```text
CSV Workspace → Сохранить изменения в наборе
```

8. Если CSV изменился внешней программой, используйте:

```text
Обновить активный лист
```

или:

```text
Обновить все листы
```

## Меню CSV Workspace

Основные пункты меню:

| Команда | Назначение |
|---|---|
| **Создать набор...** | Создать новый workspace из одного или нескольких CSV |
| **Открыть набор...** | Открыть существующий `.csvset.json` |
| **Добавить CSV в набор...** | Добавить новые CSV в уже открытый workspace |
| **Сохранить изменения в наборе** | Записать данные из листов Calc обратно в связанные CSV |
| **Обновить активный лист** | Перечитать CSV для текущего листа |
| **Обновить все листы** | Перечитать все включённые CSV набора |
| **Настройки набора...** | Изменить файлы и параметры workspace |
| **О плагине** | Информация о CSV Workspace |

Удаление CSV из набора выполняется через **Настройки набора...**.

## Горячие клавиши

Горячие клавиши используют модификаторы LibreOffice, поэтому один `Accelerators.xcu` работает на разных платформах.

| Действие | macOS | Windows / Linux |
|---|---|---|
| Открыть набор | `⌘ + ⌥ + O` | `Ctrl + Alt + O` |
| Создать набор | `⌘ + ⌥ + N` | `Ctrl + Alt + N` |
| Добавить CSV | `⌘ + ⌥ + A` | `Ctrl + Alt + A` |
| Сохранить изменения | `⌘ + ⌥ + S` | `Ctrl + Alt + S` |
| Обновить активный лист | `⌘ + ⌥ + R` | `Ctrl + Alt + R` |
| Обновить все листы | `⇧ + ⌘ + ⌥ + R` | `Ctrl + Alt + Shift + R` |
| Настройки набора | `⌘ + ⌥ + ,` | `Ctrl + Alt + ,` |

Некоторые Linux desktop environments или сторонние программы могут перехватывать `Ctrl + Alt + ...`. В таком случае используйте меню LibreOffice или переназначьте сочетание клавиш.

## Создание набора

Выберите:

```text
CSV Workspace → Создать набор...
```

Сначала появится выбор CSV-файлов. Можно выбрать несколько файлов сразу.

После этого расширение попросит сохранить manifest:

```text
*.csvset.json
```

Если manifest называется:

```text
analysis.csvset.json
```

то рабочий Calc-документ по умолчанию будет называться:

```text
analysis.csvset.ods
```

Для каждого выбранного CSV создаётся отдельный лист.

Имя листа обычно берётся из имени файла:

```text
students.csv
```

становится:

```text
students
```

Если такое имя уже существует, CSV Workspace создаёт уникальное имя, например:

```text
students (2)
```

Имена листов ограничены правилами LibreOffice Calc и длиной до 31 символа.

---

## Открытие набора

Выберите:

```text
CSV Workspace → Открыть набор...
```

и укажите:

```text
*.csvset.json
```

CSV Workspace:

1. загружает manifest;
2. проверяет связанный ODS-документ;
3. открывает существующий ODS или создаёт новый, если его нет;
4. восстанавливает отсутствующие листы из доступных CSV;
5. сообщает об отсутствующих CSV-файлах.

### Важно

Открытие существующего ODS не означает принудительное перечитывание каждого CSV.

Если нужно получить последние данные непосредственно из файлов, после открытия выполните:

```text
CSV Workspace → Обновить все листы
```

---

## Добавление CSV

В открытом workspace выберите:

```text
CSV Workspace → Добавить CSV в набор...
```

Можно выбрать несколько CSV.

Для каждого файла:

- создаётся новый лист;
- создаётся запись в manifest;
- используются параметры CSV по умолчанию;
- путь по возможности сохраняется относительно базовой папки набора.

После добавления manifest и ODS сохраняются.

---

## Обновление данных из CSV

### Обновить активный лист

Используйте:

```text
CSV Workspace → Обновить активный лист
```

Команда находит CSV, связанный с текущим листом, читает файл заново и заменяет содержимое листа актуальными данными.

Обновление выполняется безопасным способом: сначала создаётся временный лист с новыми данными. Старый лист удаляется только после успешного импорта.

Если чтение CSV завершилось ошибкой, старый лист остаётся на месте.

### Обновить все листы

Используйте:

```text
CSV Workspace → Обновить все листы
```

CSV Workspace последовательно перечитает все включённые CSV набора.

Если отдельный CSV отсутствует, расширение сообщит путь к отсутствующему файлу.

---

## Сохранение изменений обратно в CSV

Используйте:

```text
CSV Workspace → Сохранить изменения в наборе
```

Это важная команда: она записывает данные из листов Calc **обратно в реальные CSV-файлы**.

Для каждого включённого листа CSV Workspace:

1. находит связанный CSV;
2. при включённой опции создаёт резервную копию;
3. читает используемую область листа;
4. преобразует значения ячеек в текст;
5. записывает CSV во временный файл;
6. заменяет исходный CSV готовым файлом.

После выполнения показывается отчёт:

```text
✔ файл сохранён
⚠ файл или лист пропущен
✖ произошла ошибка
```

и итоговое количество успешных операций, пропусков и ошибок.

### Важно перед сохранением

Команда может перезаписать исходные CSV.

Для рабочих файлов рекомендуется оставлять включённой опцию:

```text
Backup
```

## Настройки набора

Откройте:

```text
CSV Workspace → Настройки набора...
```

В окне находятся настройки всего workspace и список подключённых CSV.

### Название

Человекочитаемое имя рабочего набора.

### Папка / базовая директория

Базовая директория, относительно которой разрешаются относительные пути к CSV.

Значение:

```text
.
```

означает директорию, в которой находится `.csvset.json`.

Например:

```text
analysis/
├── analysis.csvset.json
└── csv/
    └── students.csv
```

manifest может хранить:

```text
csv/students.csv
```

вместо полного системного пути.

Это делает набор удобнее для переноса между компьютерами.

### ODS

Имя связанного документа LibreOffice Calc.

Обычно:

```text
analysis.csvset.ods
```

### Список CSV

Каждая строка соответствует одному CSV и одному листу Calc.

Для записи можно:

- добавить CSV;
- изменить параметры;
- удалить CSV из набора.

Удаление из набора не должно удалять сам исходный `.csv` с диска. Оно удаляет связь workspace с файлом и соответствующим листом Calc.

Если ваша версия окна настроек применяет изменения только после подтверждения, после удаления нажмите **Сохранить** внизу окна.

## Параметры CSV

Параметры можно задавать глобально для новых CSV и отдельно для каждого файла.

### Кодировка

Поддерживаются:

```text
UTF-8
UTF-8-SIG
CP1251
ISO-8859-1
UTF-16LE
UTF-16BE
```

Если русские символы отображаются как:

```text
РЎС‚СѓРґРµРЅС‚
```

или другими неправильными символами, скорее всего выбрана неверная кодировка.

Для современных CSV обычно рекомендуется:

```text
UTF-8
```

Для некоторых старых русскоязычных Windows-файлов может понадобиться:

```text
CP1251
```

---

### Разделитель

Поддерживаются:

| Значение | Символ |
|---|---|
| Авто | определяется автоматически |
| Запятая | `,` |
| Точка с запятой | `;` |
| TAB | табуляция |
| Вертикальная черта | `|` |

В режиме **Авто** CSV Workspace анализирует содержимое файла и пытается выбрать один из поддерживаемых разделителей.

Если весь CSV оказался в одной колонке, откройте параметры этого CSV и укажите разделитель вручную.

Например, для:

```text
name;age;group
Alice;20;A
Bob;21;B
```

нужно выбрать:

```text
Точка с запятой (;)
```

---

### Кавычка

Обычно используется:

```text
"
```

Она нужна для значений, содержащих разделитель или перенос строки.

Пример:

```csv
name,comment
Alice,"hello, world"
```

Поле должно содержать ровно один символ.

---

### AUTO

`AUTO` означает автоматическое определение разделителя.

CSV Workspace проверяет:

```text
,
;
TAB
|
```

Если определение не удалось, используется запятая.

Для файлов с неоднозначной структурой лучше указать разделитель вручную.

---

### LF и CRLF

Это формат окончания строк при **записи CSV**.

**LF**:

```text
\n
```

обычно используется в macOS, Linux и современных кроссплатформенных инструментах.

**CRLF**:

```text
\r\n
```

традиционно используется Windows.

В большинстве случаев можно оставить:

```text
LF
```

Если конкретная Windows-программа требует CRLF, выберите:

```text
CRLF
```

---

### BOM

BOM — специальная метка в начале текстового файла.

Для обычного UTF-8 она обычно не требуется.

Включать BOM имеет смысл, если CSV должен открываться в программе, которая плохо определяет UTF-8 без этой метки.

Типичная конфигурация:

```text
UTF-8
BOM: выключен
LF
```

Для совместимости с некоторыми Windows-программами может использоваться:

```text
UTF-8
BOM: включен
CRLF
```

При явной опции `BOM` CSV Workspace добавляет BOM для UTF-8 при записи.

---

### Backup

Если параметр включён, перед перезаписью CSV создаётся резервная копия.

Рекомендуется держать включённым.

---

### Первая строка — заголовок

Параметр сохраняется в manifest для каждого CSV.

**Текущая реализация импортера не удаляет и не отделяет первую строку:** она всё равно загружается в Calc как обычная первая строка таблицы.

То есть этот флаг сейчас является метаданными набора и не изменяет чтение CSV.

---

### Спец. числа / Detect special numbers

Параметр хранится в настройках workspace.

В текущей реализации импорт выполняется через обычный CSV-reader и данные передаются в Calc как строки. Отдельной логики преобразования специальных числовых форматов этот флаг сейчас не включает.

---

## Резервные копии

При включённом `Backup` перед сохранением исходный CSV копируется.

Формат имени:

```text
имя.csv.bak.YYYYMMDD-HHMMSS
```

Например:

```text
students.csv
students.csv.bak.20260928-191320
```

После этого обновлённые данные записываются в исходный:

```text
students.csv
```

CSV Workspace использует временный файл при записи, а затем заменяет исходный файл готовой версией.

## Структура файлов набора

Рекомендуемая структура:

```text
project/
├── project.csvset.json
├── project.csvset.ods
└── csv/
    ├── students.csv
    ├── groups.csv
    └── grades.csv
```

Пример manifest:

```json
{
  "version": 1,
  "title": "project",
  "base_dir": ".",
  "document": "project.csvset.ods",
  "csv_defaults": {
    "encoding": "UTF-8",
    "delimiter": "auto",
    "quote": "\"",
    "first_line_header": true,
    "save_backup": true,
    "add_bom": false,
    "line_ending": "lf"
  },
  "sheets": [
    {
      "name": "students",
      "file": "csv/students.csv",
      "encoding": "UTF-8",
      "delimiter": ";",
      "quote": "\"",
      "first_line_header": true,
      "enabled": true
    }
  ]
}
```

### Основные поля manifest

| Поле | Назначение |
|---|---|
| `version` | версия формата manifest |
| `title` | название набора |
| `created` | время создания |
| `modified` | время последнего сохранения manifest |
| `base_dir` | базовая директория |
| `document` | связанный ODS-файл |
| `csv_defaults` | параметры CSV по умолчанию |
| `sheets` | список CSV/листов |

Каждая запись `sheets` должна иметь уникальное имя листа.

## Перенос набора на другой компьютер

Чтобы набор было удобно переносить, лучше хранить manifest, ODS и CSV в одной общей директории и использовать относительные пути.

Например:

```text
my-workspace/
├── my-workspace.csvset.json
├── my-workspace.csvset.ods
└── data/
    ├── one.csv
    └── two.csv
```

После этого можно скопировать всю директорию:

```text
my-workspace/
```

на Windows, macOS или Linux.

Если в manifest используются относительные пути, CSV Workspace сможет разрешить их относительно `base_dir`.

### Не рекомендуется

Не стоит жёстко привязывать переносимый набор к системным путям вроде:

```text
/Users/name/Desktop/file.csv
```

или:

```text
C:\Users\name\Desktop\file.csv
```

если workspace должен использоваться на разных компьютерах.

## Что происходит с форматированием и формулами

CSV — это формат данных, а не полноценная электронная таблица.

CSV не хранит:

- цвета;
- ширину колонок;
- стили;
- объединённые ячейки;
- формулы как объекты Calc;
- несколько листов в одном файле.

ODS-документ может содержать оформление Calc, но команда **Сохранить изменения в наборе** записывает в CSV значения используемой области листа.

Поэтому CSV Workspace лучше воспринимать так:

```text
CSV = данные
ODS = рабочее представление этих данных
```

Если в листе есть формула, при экспорте в CSV сохраняется значение, полученное из ячейки, а не полноценная формула Calc.

## Устранение проблем

### CSV открылся одной колонкой

Причина почти всегда в неверном разделителе.

Откройте:

```text
Настройки набора → нужный CSV → Изменить
```

и вместо `AUTO` выберите реальный разделитель:

```text
;
,
TAB
|
```

После этого выполните:

```text
Обновить активный лист
```

---

### Вместо русских букв кракозябры

Измените кодировку CSV.

Чаще всего стоит проверить:

```text
UTF-8
CP1251
UTF-8-SIG
```

После изменения параметра перечитайте лист.

---

### CSV изменился на диске, но Calc показывает старые данные

Обычное открытие существующего ODS не обязано перечитывать уже существующий лист.

Используйте:

```text
Обновить активный лист
```

или:

```text
Обновить все листы
```

---

### Появилось сообщение «Файл не найден»

Проверьте:

- существует ли CSV;
- не был ли файл переименован;
- не была ли перемещена папка;
- правильный ли `base_dir`;
- правильный ли путь указан в настройках CSV.

---

### После переноса workspace не видит CSV

Лучше использовать относительные пути и переносить всю директорию набора целиком.

Проверьте поле:

```text
base_dir
```

и пути CSV в настройках.

---

### Не удаётся сохранить CSV

Возможные причины:

- CSV открыт другой программой с блокировкой записи;
- нет прав на запись в директорию;
- файл находится на read-only диске;
- файл удалён или перемещён;
- кодировка не может представить некоторые символы.

Для максимальной совместимости используйте UTF-8.

---

### После сохранения изменились типы значений

CSV не хранит типизацию Calc так же, как ODS.

CSV Workspace при записи преобразует значения ячеек в текст и затем сериализует их как CSV.

Если важны формулы, стили, числовые форматы или другие свойства Calc, сохраняйте сам `.ods` и не рассматривайте CSV как замену ODS.

---

### Меню CSV Workspace отсутствует

1. Полностью закройте LibreOffice.
2. Запустите его снова.
3. Проверьте расширение в менеджере расширений.
4. Если установлены несколько версий CSV Workspace, удалите старые.
5. Переустановите актуальный `.oxt`.
6. Перезапустите LibreOffice.

---

### Горячая клавиша не работает

Сначала проверьте соответствующий пункт через меню.

Если меню работает, а сочетание нет, вероятен конфликт с:

- системным сочетанием клавиш;
- desktop environment;
- оконным менеджером;
- другим расширением LibreOffice.

---

### Manifest повреждён

CSV Workspace проверяет структуру manifest при загрузке.

Критичные требования:

- корень должен быть JSON-объектом;
- `version` должна поддерживаться;
- `sheets` должен быть массивом;
- у каждого элемента должны быть непустые `name` и `file`;
- имена листов не должны повторяться.

Если manifest редактируется вручную, перед сохранением рекомендуется сделать его копию.

---

## Ограничения текущей версии

На текущем этапе следует учитывать:

- CSV Workspace работает с CSV как с текстовыми табличными данными;
- форматирование Calc не переносится в CSV;
- формулы не сохраняются в CSV как формулы;
- первая строка загружается как обычная строка независимо от флага `first_line_header`;
- `detect_special_numbers` хранится в настройках, но отдельное преобразование специальных числовых форматов сейчас не реализовано;
- автоматическое определение разделителя ограничено символами `,`, `;`, `TAB`, `|`;
- при неоднозначном CSV лучше задавать разделитель вручную;
- удаление CSV из workspace не предназначено для удаления физического `.csv` с диска.

---

## Безопасная работа с данными

Для важных наборов рекомендуется:

1. Оставить `Backup` включённым.
2. Хранить manifest, ODS и CSV в одной общей директории.
3. Использовать относительные пути.
4. Перед массовым сохранением проверить, что листы действительно содержат данные, которые должны попасть в CSV.
5. Использовать **Обновить** только если нужно заменить данные листа содержимым CSV.
6. Использовать **Сохранить изменения в наборе** только если нужно сделать обратное — заменить содержимое CSV данными из Calc.

Запомнить направление операций можно так:

```text
Обновить:
CSV  →  Calc

Сохранить изменения:
Calc →  CSV
```

Это две противоположные операции.

---

## Обновление и удаление расширения

### Обновление

Рекомендуемый порядок:

1. Закройте открытые workspace-документы.
2. Откройте менеджер расширений LibreOffice.
3. Удалите старую версию CSV Workspace.
4. Полностью перезапустите LibreOffice.
5. Установите новый `csvworkspace.oxt`.
6. Снова перезапустите LibreOffice.

Ваши:

```text
*.csvset.json
*.csvset.ods
*.csv
```

не являются частью установленного расширения и не должны удаляться при обычном удалении `.oxt`.

### Удаление

Удалите CSV Workspace через менеджер расширений LibreOffice и перезапустите программу.

Рабочие наборы останутся на диске и при необходимости могут быть открыты вручную как обычные ODS/CSV-файлы.

## Форматы файлов

CSV Workspace использует:

```text
.csvset.json   конфигурация рабочего набора
.csvset.ods    рабочий документ LibreOffice Calc
.csv/.txt/.tsv исходные табличные файлы
```

Manifest записывается в UTF-8 и обновляет поле `modified` при сохранении.

---

**CSV Workspace** создан для ситуаций, когда несколько CSV логически являются одним рабочим проектом, но должны оставаться отдельными CSV-файлами на диске.
